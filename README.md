A small deterministic Python program that writes one one-line comedy joke (94 characters) to `/output/entry.txt` for the make.fun One-Liner Marathon. It drafts eight candidate one-liners, scores each against the judge's published brief — a real joke with a punchline, surprise, economy, distinct voice, holding up on a second read — and writes the highest-scoring one. Deterministic, no network, no dependencies.

The winning line:

> My password is so strong even I can't log in, which makes me the only hacker I've ever beaten.

## Run it

```sh
python3 main.py
```
